# MAGICwhisp.github.io

A cozy, fantasy-inspired Minecraft skins and creations website.

## Add your images and downloads

- Put hero, pack, skin, and about images in `assets/images/`.
- Put individual `.png` skins in `assets/skins/`.
- Put downloadable `.zip` packs in `assets/packs/`.
- Replace each `image-placeholder` box with an `<img>` element and update the `src` path.
- Update the download `href` values in `skin.html` and `pack.html`.

The site is plain HTML, CSS, and JavaScript, so it works with GitHub Pages without a build tool.
